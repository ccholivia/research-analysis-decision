# Research Methods Atlas

A free, static, responsive educational website covering statistics, machine learning and deep learning. Includes an interactive method finder, searchable method library, real research scenarios, assumptions and reporting tips.

## Host free on GitHub Pages

1. Create a **public** GitHub repository, e.g. `research-methods-atlas`.
2. Upload the **contents of this folder** (not the ZIP file) to the repository root. Commit changes.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, then `main` and `/ (root)`. Save.
5. GitHub will show your website URL, typically `https://YOUR-USERNAME.github.io/research-methods-atlas/`.

No Node.js, build process, database, server, API keys, or paid services needed.

## Customize

- Edit `index.html` for site copy and links.
- Edit `styles.css` for colors and layout.
- Edit the `raw` array in `app.js` to add or revise methods.
- `research_analysis_field_guide.pdf` is included for the PDF download button.

## Notes

Educational guidance only: method choice depends on sampling, study design, assumptions and the exact estimand. Referenced book links point to third-party sites and are not bundled.
